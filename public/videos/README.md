# Vídeo do Hero

O arquivo original preservado é:

`3video.mp4`

O Hero usa duas versões otimizadas, sem áudio e com carregamento rápido:

- `/videos/hero-desktop-v2.mp4` — 1280×720 para desktop e tablet.
- `/videos/hero-mobile-v2.mp4` — recorte vertical 360×640 para celular.

As duas versões usam MP4/H.264 com `faststart`. Ao trocar o vídeo original, gere novamente essas variantes antes do deploy.
